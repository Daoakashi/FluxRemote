# Conditions d'utilisation de FluxLite, Flux Remote et de l'interface web de Flux

*Version 2026-10. Ce texte est affiché dans chaque application, qui le complète avec le nom du responsable et la durée de conservation choisis sur le PC Flux. Quand la version change, l'utilisateur doit l'accepter de nouveau.*

**1. Objet.**
- FluxLite (Android), Flux Remote (ordinateur) et l'interface web permettent aux personnes autorisées de consulter en direct les caméras d'un système de vidéosurveillance Flux, d'en recevoir les alertes et, si leur compte y est autorisé, de piloter certains réglages.
- Elles ne fonctionnent qu'avec un serveur Flux privé ; ce n'est pas un service public.

**2. Accès et compte.**
- Votre compte est personnel.
- Il est validé par le responsable du serveur, qui décide des caméras et des commandes auxquelles vous avez accès.
- Gardez votre mot de passe secret et signalez sans délai toute utilisation suspecte.
- Le responsable peut suspendre ou supprimer un compte à tout moment.
- Un même compte peut être utilisé sur plusieurs serveurs Flux si leurs responsables l'acceptent : chaque serveur garde ses propres règles et ses propres données.

**3. Bon usage des images.**
- Les images montrent des personnes : ce sont des données personnelles.
- Vous les consultez uniquement pour la mission de sécurité qui vous est confiée.
- Il est interdit de les enregistrer, de faire des captures d'écran, de les diffuser ou de les utiliser à d'autres fins, sauf instruction écrite du responsable (par exemple pour transmettre une preuve à la police).
- Toute infraction peut entraîner la suppression du compte et engager votre responsabilité.

**4. Responsable du traitement.**
- Le responsable du traitement de vos données est l'entreprise qui exploite le serveur Flux auquel vous vous connectez. Son nom est affiché dans l'application.
- Les données sont stockées sur son propre serveur Flux, et non chez l'éditeur du logiciel (DMS Security) ni chez un hébergeur tiers.

**5. Données vous concernant.**
- Les données conservées sont :
  - nom, prénom, adresse mail et société indiquée ;
  - empreinte chiffrée du mot de passe, jamais le mot de passe lui-même ;
  - date d'acceptation des présentes conditions ;
  - informations techniques de connexion : modèle de l'appareil ou navigateur, version de l'application, adresse IP, dates.
- Elles servent à sécuriser l'accès. Base légale : exécution du contrat et intérêt légitime de sécurité.
- Elles sont conservées tant que le compte existe.

**6. Alertes et journal.**
- Les alertes et leurs photos sont conservées sur le serveur pendant la durée choisie par le responsable, puis effacées.
- Les applications n'enregistrent aucune image dans la galerie de l'appareil.
- Sur Android, les captures d'écran peuvent être bloquées (réglage activé par défaut).

**7. Sécurité.**
- Les échanges sont chiffrés (TLS).
- FluxLite et Flux Remote vérifient la clé unique du serveur et refusent tout autre serveur.
- Hors du réseau local, les échanges passent par le relais Flux sans pouvoir y être lus (chiffrement de bout en bout).
- Les commandes à distance sont notées dans le journal de Flux avec votre nom.

**8. Vos droits (RGPD).**
- Vous pouvez accéder à vos données, les rectifier, les exporter, demander leur effacement, vous opposer à leur traitement ou en demander la limitation.
- L'onglet Compte permet d'exporter vos données et de supprimer votre compte.
- Pour toute autre demande, adressez-vous au responsable.
- Vous pouvez aussi saisir l'autorité de protection des données (APD en Belgique, CNIL en France).

**9. Feedback.**
- Le bouton Feedback ouvre votre messagerie ou GitHub avec un message que vous relisez avant de l'envoyer. Rien n'est envoyé automatiquement.
- Le message est adressé à l'éditeur (DMS Security), pas au responsable du serveur.

**10. Logiciel libre.**
- Les applications sont des logiciels libres (GNU AGPL-3.0), fournies sans garantie.
- Elles ont été développées avec l'aide d'outils d'intelligence artificielle.
- Code source : https://github.com/Daoakashi.

**11. Évolution.** Ces conditions peuvent évoluer ; la nouvelle version vous sera présentée et devra être acceptée pour continuer.
